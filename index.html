۲ سال آذر ۱۴۰۳ — تاکنون

مشارکت در توسعه و نگهداری یک سامانه ERP سازمانی با بیش از ۵۰ زیرسیستم و حدود ۱۰ هزار کاربر، در حوزه‌های مختلف کسب‌وکار:

  • مدیریت کارها و جلسات
  • CRM
  • امور حقوقی و مجامع
  • حاکمیت شرکتی و سهامداری
  • کارگزینی و حقوق و دستمزد

مسئولیت‌ها و مشارکت‌های فنی

  • توسعه قابلیت‌های کسب‌وکاری و پیاده‌سازی Business Logic در زیرسیستم‌های مختلف ERP.
  • توسعه API ها، کنترلرها و سرویس‌های کاربردی مبتنی بر ASP.NET و معماری چندلایه.
  • کار با SQL Server و توسعه، نگهداری و دیباگ Stored Procedure های پیچیده.
  • استفاده از Entity Framework برای توسعه و مدیریت داده‌ها.
  • توسعه قابلیت‌های Real-Time و ارتباطات مبتنی بر WebSocket.
  • طراحی و توسعه تقویم سازمانی برای مدیریت جلسات، رویدادها و وظایف.
  • توسعه کامپوننت‌ها و Helper های قابل استفاده مجدد جهت بهبود قابلیت نگهداری سیستم.
  • مشارکت در ماژولار کردن زیرسیستم‌ها و بهبود ساختار معماری لایه‌ای.
  • همکاری در فرآیند مهاجرت تدریجی سامانه از .NET Framework 4.5 به .NET 10.
  • بازطراحی بخش‌هایی از رابط کاربری شامل صفحه ورود، منوها و گریدهای برخی زیرسیستم‌ها.
